# وصل — VPN شخصی برای ایران

VPN شخصی روی سرور خودتان، با **Xray-core** و پروتکل **VLESS + REALITY**؛ یکی از مقاوم‌ترین روش‌ها در برابر فیلترینگ و DPI در ایران.

## چرا REALITY؟

- برای سیستم فیلترینگ، ترافیک شما شبیه اتصال HTTPS عادی به یک سایت معتبر (مثلاً `www.microsoft.com`) دیده می‌شود.
- **نه دامنه لازم دارد، نه گواهی SSL.** فقط یک VPS.
- اگر کسی (یا سیستم فیلترینگ) سرور شما را پروب کند، جواب سایت واقعی را می‌گیرد.

دو پروفایل ساخته می‌شود:

| پروفایل | پورت | کاربرد |
|---|---|---|
| `vision` (VLESS + XTLS-Vision + REALITY) | 443 | اصلی؛ سریع‌ترین |
| `xhttp` (VLESS + XHTTP + REALITY) | 8443 | پشتیبان؛ وقتی Vision کند شد یا قطع شد |

---

## لینک اشتراک: همه‌ی روش‌ها در یک لینک

بعد از نصب، هر کاربر یک **لینک اشتراک** دارد (`vasl sub`). این لینک را یک بار در Hiddify یا v2rayNG وارد کنید؛ برنامه همه‌ی روش‌های زیر را می‌گیرد و هر ساعت به‌روزشان می‌کند. اگر لینک را در مرورگر باز کنید، صفحه‌ای فارسی با QR Code و دکمه‌ی کپی می‌بینید.

| روش | پروتکل | پورت | کی به درد می‌خورد |
|---|---|---|---|
| `vision` | VLESS + REALITY روی TCP | 443/tcp | روش اصلی |
| `hy2` | Hysteria2 با پوشش Salamander | 443/udp | خیلی سریع؛ اگر اپراتور UDP را نبندد |
| `tuic` | TUIC v5 | 8443/udp | پشتیبان Hysteria2 |
| `cdn` | VLESS + WebSocket از طریق تونل رایگان Cloudflare | — | وقتی IP سرور فیلتر شد؛ بدون نیاز به دامنه |
| `xhttp` | VLESS + XHTTP + REALITY | 8443/tcp | فقط در v2rayN / v2rayNG |

> آدرس تونل Cloudflare (`*.trycloudflare.com`) با هر ری‌استارت عوض می‌شود، ولی لینک اشتراک همیشه آدرس جدید را می‌دهد؛ فقط در برنامه «Update subscription» را بزنید.

## ۱. خرید سرور (VPS)

- **سیستم‌عامل:** Ubuntu 22.04 یا 24.04
- **منابع:** ۱ هسته و ۱ گیگ رم کافی است.
- **موقعیت:** آلمان، هلند، فنلاند یا ترکیه معمولاً پینگ خوبی از ایران دارند.
- **ارائه‌دهنده‌ها:** Hetzner، DigitalOcean، Vultr، Contabo و…
  پرداخت از ایران معمولاً با ارز دیجیتال یا از طریق واسطه‌ها انجام می‌شود. بعضی ارائه‌دهنده‌ها مثل Vultr پرداخت کریپتو را مستقیم قبول می‌کنند.

> 💡 بعد از خرید، اول از ایران IP سرور را `ping` کنید. اگر جواب نداد، IP از قبل فیلتر است؛ از ارائه‌دهنده IP جدید بخواهید یا سرور را عوض کنید.

## ۲. نصب روی سرور

با SSH وارد سرور شوید (ویندوز: PowerShell، اندروید: Termux یا JuiceSSH):

```bash
ssh root@IP_SERVER
```

بعد:

```bash
apt update && apt install -y git
git clone https://github.com/barismairan-source/vasl.git
cd vasl
sudo bash install.sh
```

> اگر ریپو خصوصی است، فایل‌های `install.sh` و `vasl.sh` را با `scp` به سرور منتقل کنید، یا ریپو را عمومی کنید. این ریپو هیچ اطلاعات محرمانه‌ای ندارد؛ کلیدها روی خود سرور ساخته می‌شوند.

در پایان نصب، دو لینک `vless://...` نمایش داده می‌شود.

### تنظیمات اختیاری

```bash
sudo SNI=www.speedtest.net VISION_PORT=443 XHTTP_PORT=8443 FIRST_USER=ali bash install.sh
```

## ۳. اتصال از گوشی و کامپیوتر

| سیستم | برنامه‌ی پیشنهادی |
|---|---|
| اندروید | **v2rayNG** یا **Hiddify** |
| iOS / مک | **Streisand**، **V2Box** یا **Hiddify** |
| ویندوز | **v2rayN** یا **Hiddify** |
| لینوکس | **Hiddify** یا **v2rayN** |

برای اضافه کردن کانفیگ دو راه دارید:

- لینک `vless://` را کپی کنید و در برنامه «Import from clipboard» را بزنید.
- روی سرور `vasl qr user1` را اجرا کنید و QR را با گوشی اسکن کنید.

> 🇮🇷 در Hiddify گزینه‌ی **Region = Iran** را انتخاب کنید تا سایت‌های ایرانی (بانک، اسنپ و…) مستقیم باز شوند و از VPN رد نشوند. این کار هم سرعت را بیشتر می‌کند و هم ریسک شناسایی سرور را کم.

## ۴. مدیریت

```bash
vasl list              # فهرست کاربرها
sudo vasl add mom      # کاربر جدید (برای هر نفر/دستگاه یکی بسازید)
sudo vasl del mom      # حذف کاربر
vasl sub               # لینک اشتراک هر کاربر (همه‌ی روش‌ها)
vasl links             # همه‌ی لینک‌ها
vasl qr mom            # QR Code
sudo vasl diag         # عیب‌یابی کامل وقتی وصل نمیشه
vasl status            # وضعیت و لاگ
sudo vasl update       # به‌روزرسانی Xray-core
```

## ۵. اگر وصل نشد

1. **`vasl status`** را بزنید و ببینید سرویس `active (running)` است یا نه.
2. **پروفایل دیگر را امتحان کنید.** اگر `vision` کار نکرد، `xhttp` را تست کنید (و برعکس).
3. **دامنه‌ی استتار (SNI) را عوض کنید.** چند دامنه را تست کنید:
   ```bash
   vasl sni-test www.microsoft.com www.speedtest.net dl.google.com www.samsung.com
   ```
   دامنه‌ای خوب است که ✅ بگیرد، زمان اتصالش از سرور کم باشد (ترجیحاً در همان دیتاسنتر یا کشور) و در ایران فیلتر نباشد. بعد نصب را با SNI جدید تکرار کنید:
   ```bash
   sudo SNI=دامنه_جدید bash install.sh --reinstall
   ```
   ⚠️ `--reinstall` کلیدها را عوض می‌کند و همه باید لینک‌های جدید را وارد کنند.
4. **روی اینترنت دیگری تست کنید** (همراه اول، ایرانسل، ADSL). گاهی فقط یک اپراتور مشکل دارد.
5. **IP فیلتر شده؟** اگر `ping` به IP سرور از ایران جواب نمی‌دهد ولی از خارج جواب می‌دهد، IP مسدود شده و باید IP جدید بگیرید.

## نکات امنیتی

- لینک‌ها را فقط به افراد مورد اعتماد بدهید. هر کس لینک را داشته باشد می‌تواند وصل شود.
- برای هر نفر یک کاربر جدا بسازید تا اگر لازم شد، فقط دسترسی همان یک نفر را قطع کنید.
- سرور را عمومی نفروشید و پخش نکنید. ترافیک زیاد و ناشناس سرور را زودتر لو می‌دهد.
- BitTorrent روی سرور مسدود است تا از شکایت کپی‌رایت و بسته شدن سرور جلوگیری شود.
